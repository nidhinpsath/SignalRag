# SignalRAG — Hallucination Detection in RAG Using Externally Observable Signals

A lightweight black-box hallucination detection framework for Retrieval-Augmented Generation (RAG) systems. SignalRAG extracts 17 externally observable signals from the retrieval, generation, and alignment stages of a RAG pipeline and trains supervised classifiers to predict whether a generated answer is hallucinated — without requiring access to internal model states, weights, or logits.

## Pipeline

```
RAGTruth QA queries
        ↓
Qwen2.5-7B-Instruct (4-bit NF4) — answer generation
        ↓
Signal extraction (17 signals)
    ├── Retrieval signals (6)  — cosine similarity via all-MiniLM-L6-v2
    ├── Generation signals (8) — token log-probabilities from model.generate()
    └── Alignment signals (3)  — ROUGE-L, embedding similarity, lexical overlap
        ↓
3-Judge LLM ensemble — majority vote faithfulness label
    ├── GPT-oss-120b (Groq Account 1)
    ├── GPT-oss-20b  (Groq Account 2)
    └── Qwen3.8-27b  (Groq Account 3)
        ↓
Supervised classifier training (LR / MLP / Random Forest / XGBoost)
5-fold GridSearchCV with Pipeline-wrapped StandardScaler (no CV leakage)
        ↓
AUROC evaluation on held-out test set
```

## Dataset

[RAGTruth](https://huggingface.co/datasets/wandb/RAGTruth-processed) (Niu et al., ACL 2024) — QA subset, query-level deduplicated (839 unique queries). 200 training examples, 100 held-out test examples. Downloaded automatically — no manual setup required.

## Repository structure

```
signalrag/                  Python package (importable, pip-installable)
  config.py                 Global constants — dataset IDs, model names, feature list
  data.py                   load_ragtruth() — loads and filters the RAGTruth QA subset
  signals.py                SignalExtractor — loads embedder + LLM, extracts all 17 signals
  labeling.py               EnsembleJudge — 3-judge LLM ensemble for faithfulness labelling
  classifier.py             SignalRAGClassifier — estimator + scaler pair; factory builders
  utils.py                  Shared stateless helpers

notebooks/
  01a_train.ipynb           Run pipeline on 200 train records, save ragtruth_train_signals.csv
  01b_test.ipynb            Run pipeline on 100 test records, save ragtruth_test_signals.csv
  02_eda.ipynb              Label distribution, signal distributions, missing value checks
  03_model_training.ipynb   Train LR / MLP / RF / XGBoost with 5-fold CV, save models
  04_evaluation.ipynb       Evaluate on held-out test set (run exactly once)
  05_ablation.ipynb         Signal group ablation study
  06_demo.ipynb             Run SignalRAG on a custom query / passage / answer

data/                       Cached signal CSVs (committed — skip 01a/01b if you just want to verify results)
models/                     Serialised classifiers (gitignored — generated by 03)
```

## Hardware

- GPU: NVIDIA T4 or better (>= 6 GB VRAM) — required for 4-bit NF4 quantisation
- Runtime: ~90 minutes for notebooks 01a + 01b (200 train + 100 test examples)

## Setup — Google Colab (recommended)

1. Upload `signalrag_restructured.zip` to Colab, then run the following cells in an untitled notebook:

```python
# 1. Unzip
!unzip -o signalrag_restructured.zip -d /content/

# 2. Install packages Colab does not pre-install
!pip install -q bitsandbytes faiss-cpu rouge-score groq

# 3. Install the signalrag package
!pip install -q -e /content/signalrag/

# 4. Set Groq API keys
import os
os.environ["GROQ_API_KEY_1"] = "gsk_..."   # GPT-oss-120b
os.environ["GROQ_API_KEY_2"] = "gsk_..."   # GPT-oss-20b
os.environ["GROQ_API_KEY_3"] = "qsk_..."   # Qwen3.8-27b

# 5. Run notebooks in order
import subprocess, sys
for nb in ["01a_train.ipynb", "01b_test.ipynb", "02_eda.ipynb",
           "03_model_training.ipynb", "04_evaluation.ipynb", "05_ablation.ipynb"]:
    print(f"Running {nb}...")
    subprocess.run([sys.executable, "-m", "nbconvert", "--to", "notebook",
                    "--execute", "--inplace",
                    "--ExecutePreprocessor.timeout=3600", nb],
                   cwd="/content/signalrag/notebooks", check=True)
    print(f"Done: {nb}")
```

> **API key rate limits:** Notebooks `01a` and `01b` make ~300 Groq API calls in total. If you hit rate limits, use a second set of 3 keys for `01b`. Each notebook caches its output CSV — if the file already exists the pipeline is skipped automatically.
